WHAT-IF Project – WP4 Prototype Simulation Model

This directory contains the prototype agent-based simulation model developed
as part of Work Package 4 of the WHAT-IF project (ERC Horizon Grant Agreement #101177574).

Contributors: Aytalina Kulichkina, Taehee Kim, Annie Waldherr, David Garcia


Structure
------------
./what_if_prototype_prelim.nlogox


Requirements
------------
- NetLogo 7.0.3 or later
Download from: https://ccl.northwestern.edu/netlogo/download.shtml


Running the model
-----------------
1. Install NetLogo (see link above).
2. Open NetLogo.
3. Go to File > Open and select what_if_prototype_prelim.nlogox.
4. Click 'Setup' to initialise the model, then 'Go' to run it.

For further details on the model design and parameters, refer to the
accompanying deliverable report.
